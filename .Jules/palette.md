## 2024-05-24 - Image Badge Accessibility Context

**Learning:** Screen readers need context beyond a project or technology name for image badges. When a badge links to a release, the alt text must indicate the destination. When it's a technology stack badge, the alt text must indicate the category.
**Action:** Always expand alt text on image badges (like shields.io) to include the destination context for links (e.g., "latest release") or the category context for standalone technologies (e.g., "programming language badge").
