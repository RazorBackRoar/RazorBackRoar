## 2024-05-24 - Improve accessibility of image badges in README
**Learning:** Screen readers need context beyond the visible text in image badges. Badges wrapped in links should describe the destination (e.g., 'App Name latest release'), and technology badges should clarify their category (e.g., 'programming language badge').
**Action:** Always expand alt text for badges to provide destination context for links and category context for standalone technology indicators.
