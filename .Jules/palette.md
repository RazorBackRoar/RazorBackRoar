## 2024-05-24 - Explicit Alt Text for Markdown Badges

**Learning:** Image badges (e.g., Shields.io) wrapped in anchor tags require destination context in their `alt` text (e.g., '[App Name] latest release') rather than just the project name, and standalone technology badges need category context (e.g., 'Python programming language badge') to ensure accessibility for screen reader users.
**Action:** Always expand `alt` attributes on image badges to include their functional destination or category context rather than just the literal text displayed.
