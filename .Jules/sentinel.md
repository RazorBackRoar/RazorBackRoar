## 2024-03-21 - [GitHub Messaging Vulnerability Disclosure Risk]

**Vulnerability:** Contact instructions in SECURITY.md and CODE_OF_CONDUCT.md told users to "message @RazorBackRoar on GitHub" for private reports, but GitHub does not support direct private messaging.
**Learning:** This caused users to potentially create public issues or comments to report vulnerabilities, exposing them publicly before they could be fixed.
**Prevention:** Always verify that communication platforms support private messaging before directing users there for security reports. Direct users to an explicit email address or dedicated private reporting feature.
