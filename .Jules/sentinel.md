## 2026-07-29 - Missing Secure Communication Channel

**Vulnerability:** Security and CoC documentation instructed users to send direct messages on GitHub, which is an unsupported feature, preventing secure private reporting.
**Learning:** Security processes fail when the specified communication channels do not exist, potentially forcing reporters to use public channels (like issues) for sensitive vulnerabilities.
**Prevention:** Verify that all reporting channels mentioned in documentation actually exist and support the required level of privacy.
