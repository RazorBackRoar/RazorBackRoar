## 2024-05-24 - Insecure Contact Channel in Documentation

**Vulnerability:** Security and Code of Conduct documentation instructed users to report sensitive issues via GitHub direct messages, a feature that doesn't exist. This risks users defaulting to public issues to report vulnerabilities.
**Learning:** Standard boilerplate templates often assume the existence of private messaging on platforms or copy patterns from other platforms without verifying.
**Prevention:** Always verify that proposed contact methods are functional and private. Direct users to an explicit email address or the email listed on their profile for sensitive reports.
