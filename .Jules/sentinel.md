## 2024-10-18 - [Invalid Contact Methods for Security & Conduct Reporting]

**Vulnerability:** The documentation instructed users to report security vulnerabilities and code of conduct violations by messaging the maintainer on GitHub. However, GitHub does not support direct private messaging, leaving users with no valid or secure way to report sensitive issues.
**Learning:** Contact methods must be verified for feasibility before being documented, especially for sensitive reporting channels. Relying on platform assumptions can inadvertently prevent critical issues from being reported.
**Prevention:** Always provide direct, verifiable contact methods (like an email address or a specific reporting platform) instead of relying on non-existent features of hosting platforms. Ensure that all documented procedures can be actively executed by a user.
