All apps ship as **Apple Silicon DMGs**. They are ad-hoc signed. On first launch, right-click → **Open**, or allow the app under **Privacy & Security → Open Anyway**.

## About

I'm a guy in my 30s from the Deep South. I build native macOS apps for Apple Silicon — Python and PySide6 when the job is a desktop tool, Swift and SwiftUI when it should feel like a Mac app, and AppKit for Looper.

I like shipping things people can actually download. Local-first. No account, no cloud, no telemetry.

When I'm not writing apps, I'm usually knee-deep in a Switch library.
